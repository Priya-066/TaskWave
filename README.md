🌊 Task Wave

Flow through your day with ease

📝 Description

Task Wave is a simple yet powerful ReactJS-based to-do list application that helps users organize and manage their daily tasks efficiently.
You can categorize tasks (Work, Personal, General), set priorities, mark them as complete, and track your overall progress — all in one elegant interface.

🚀 Features

✅ Add tasks with category and priority
✅ Mark tasks as complete or incomplete
✅ Auto-sorted task sections by category
✅ Progress tracker showing completion percentage
✅ LocalStorage support (your data stays even after refresh)
✅ Fully responsive design with a clean, modern UI

🛠️ Tech Stack

ReactJS

JavaScript (ES6+)

CSS3 (custom styling)

LocalStorage API
